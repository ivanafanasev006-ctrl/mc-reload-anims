# Текстуры и интерфейс

- `author/` — то, что прислал автор (PNG, `.bbmodel`, файлы и скриншоты MCreator), как есть.
- `refined/` — доработанные версии с теми же именами: стиль Minecraft, палитра, симметрия,
  читаемость в игре; для UI — экраны, которые потом пишутся в моде кодом.

Присланное — каркас, а не готовая работа; правила доработки — в `CLAUDE.md` в корне репозитория.
Готовые текстуры и экраны переезжают в `assets` мода.
