# Модель игрока Kinetrix для Blockbench

`kinetrix_rig.bbmodel` — модель игрока, разрезанная там же, где её сгибает Kinetrix: в локтях, коленях и
пояснице. Анимация, сделанная на ней, проигрывается в игре со сгибами суставов: что видно в
Blockbench, то и будет на игроке (расхождение меньше 1 пикселя модели).

Скачать: [kinetrix_rig.bbmodel](https://github.com/ivanafanasev006-ctrl/mc-reload-anims/raw/main/tools/blockbench/kinetrix_rig.bbmodel)

## Открыть

1. Blockbench в браузере: <https://web.blockbench.net> (ставить ничего не нужно) или программа для ПК:
   <https://www.blockbench.net/downloads>. Подходит версия 4 и 5.
2. File → Open Model (или перетащить файл в окно).
3. Справа вверху переключиться в режим **Animate**.
4. Слева список анимаций, в нём три примера: `bend_demo` (сгибы по очереди), `slide` (подкат),
   `cross_guard` (блок двумя мечами накрест). Выберите любой и нажмите пробел.

На модели учебный скин: правые руки и ноги красные, левые синие, линии суставов темнее, на груди
спереди метка. Правая — правая самого игрока (если смотреть ему в лицо, она слева на экране).
Скин можно заменить любым скином 64×64 (вкладка Textures), разметка стандартная.

## Кости

| Кость | Что двигает |
|---|---|
| `body` | Весь игрок целиком, точка вращения в бёдрах. Сдвиг опускает/поднимает/смещает игрока (подкат, присед, прыжок), поворот наклоняет и переворачивает (падение, кувырок, наклон в беге). |
| `torso` | Весь корпус вместе с головой и руками, поворачивается у шеи, как туловище в обычном Minecraft. Поворот по Y — развернуть плечи влево/вправо относительно ног. |
| `chest` | Верхняя половина корпуса, гнётся в пояснице: наклон вперёд, назад, вбок. Голова и руки идут вместе с ней. |
| `head` | Голова. |
| `right_arm`, `left_arm` | Рука от плеча до локтя, крутится в любую сторону. |
| `right_forearm`, `left_forearm` | Предплечье, гнётся в локте. |
| `right_leg`, `left_leg` | Нога от бедра до колена. |
| `right_shin`, `left_shin` | Голень, гнётся в колене. |
| `right_item_sword` | Меч в правой руке. Поворот и сдвиг этой группы поворачивают оружие в кулаке (клинок вниз, обратный хват). |
| `right_item_bow` | Лук в правой руке. Скрыт: в списке справа (Outliner) нажмите на глаз, чтобы показать. |
| `left_item_sword` | Меч в левой руке, тоже скрыт. |

Предметы в модели только для того, чтобы видеть оружие во время анимации: в игре в руке будет
тот предмет, который держит игрок, но повёрнутый так же.

## Правила, чтобы в игре вышло так же

- **Локоть и колено только сгибаются.** Предплечье и голень можно сгибать в любую сторону поперёк
  кости, но крутить вокруг собственной длины нельзя: в игре такой поворот отбрасывается (конвертер
  про это напишет). Нужно развернуть кисть — поворачивайте всю руку от плеча.
- Естественные направления: локоть вперёд, колено назад, поясница вперёд. В обратную сторону гнуть
  можно, но в игре точка сгиба окажется на другой стороне сустава (разница меньше пикселя, на глаз
  незаметна).
- **`chest` не скручивать вокруг вертикали**, это тоже отбрасывается. Развернуть плечи — поворот
  `torso` по Y (ноги остаются как были). `chest` гнётся вперёд, назад (X) и вбок (Z).
- **Голова без ключей** в игре смотрит туда, куда смотрит игрок, даже если корпус развёрнут. Чтобы
  голова поворачивалась вместе с корпусом, поставьте на `head` хотя бы один ключ.
- Сдвигать (Move) можно `body`, `torso`, голову, руки и ноги целиком и предметы. У `chest`,
  предплечий и голеней работает только поворот: в игре сустав не разрывается, их сдвиг пропадёт.
- Масштаб (Scale) не переносится.
- Кривые ключей: Linear, Smooth (catmullrom) и Step переносятся точно; Bezier читается как Linear.
  В значениях только числа, без формул Molang.
- Режим повтора анимации (правый клик по анимации → Properties → Loop): **Play once** — сыграть
  один раз, **Loop** — по кругу, **Hold on last frame** — застыть в последней позе (для стоек и блоков).
- Имя анимации — латиницей в нижнем регистре через `_` (`slide_kick`, `bow_backstep`). Это имя станет
  именем анимации в игре.
- Длину лучше ставить с запасом на возврат: в последнем ключе вернуть кости в ноль, если после
  анимации игрок должен стоять как обычно.

## Как делать анимацию

1. Справа в Outliner выберите кость (или кликните по ней на модели).
2. Внизу на шкале времени поставьте курсор на нужное время.
3. Инструмент Rotate (клавиша R): тяните кольца. Ключ создаётся сам.
4. Пробел — проиграть. Новая анимация: кнопка «+» в списке анимаций слева.

Числа в полях ключа для Blockbench 5 (в браузере сейчас он; в Blockbench 4 у вращения по X и Y знак
обратный, поэтому проще ориентироваться на кольца):

| Движение | Кость и ось |
|---|---|
| Рука вперёд/вверх | `*_arm` X + |
| Правая рука в сторону | `right_arm` Z + (левая: Z −) |
| Согнуть локоть | `*_forearm` X + |
| Нога вперёд | `*_leg` X + |
| Согнуть колено | `*_shin` X − |
| Наклон корпуса вперёд | `chest` X − |
| Кивок вниз | `head` X − |
| Весь игрок откидывается назад | `body` X + |
| Поворот к левому плечу игрока | Y + |

## Противник рядом (две фигуры)

Для приёмов против кого-то (подкат под противника, блок удара, удар в спину) в модель можно добавить
вторую фигуру: [kinetrix_opponent.bbmodel](https://github.com/ivanafanasev006-ctrl/mc-reload-anims/raw/main/tools/blockbench/kinetrix_opponent.bbmodel).
Она стоит в двух блоках перед игроком лицом к нему, серо-зелёная, кости называются `enemy_*`.

1. Откройте свою модель (сделанную из `kinetrix_rig.bbmodel`).
2. File → Import → **Import Project** → `kinetrix_opponent.bbmodel` (или открыть его вкладкой и
   File → Import → Import Open Project).
3. Противника можно двигать и анимировать в тех же анимациях (замах, падение) — это только
   ориентир: конвертер берёт кости игрока, `enemy_*` в игру не попадают. Подвинуть его ближе или
   дальше — сдвиг группы `enemy` в режиме Edit.

Не вставляйте так второй `kinetrix_rig.bbmodel`: у копии будут те же имена анимаций, а кости
Blockbench переименует в `body2`, `right_arm2`, и анимации перемешаются.

Просто держать две разные модели открытыми можно и так: File → Open Model ещё раз — каждая модель
открывается своей вкладкой сверху. Плагин Blockbench MCP работает с той вкладкой, которая выбрана.

## Как прислать

Сохраните модель (File → Save Model, файл `.bbmodel`; одна модель может содержать сколько угодно
анимаций) и любым способом передайте её мне: в чат или загрузите в репозиторий в папку
[`tools/blockbench/animations`](https://github.com/ivanafanasev006-ctrl/mc-reload-anims/tree/main/tools/blockbench/animations)
(на GitHub: Add file → Upload files). Самотест (Actions → Visual self-test → Run workflow,
в поле `only` написать `^99`) переводит все модели из этой папки для игры, проигрывает каждую
анимацию в Minecraft с Kinetrix и выкладывает скриншоты и картинки-сравнения
(`bbpreview_<имя>.png`) в ветку `selftest`.

## Claude прямо в Blockbench (Blockbench MCP)

Сторонний плагин [Blockbench MCP](https://github.com/jasonjgardner/blockbench-mcp-plugin) даёт Claude,
запущенному на том же ПК, видеть открытую модель и менять её: кости, анимации, ключи, шкалу времени,
снимки экрана. Облачная сессия до вашего ПК не достаёт, поэтому Claude запускается у вас.

1. Blockbench для ПК (не браузерный): <https://www.blockbench.net/downloads>.
2. File → Plugins → Load Plugin from File → `mcp.js` (или Load Plugin from URL →
   `https://jasonjgardner.github.io/blockbench-mcp-plugin/mcp.js`).
3. File → Settings → General: снять галочку **Enable risky_eval** (иначе любой подключившийся может
   выполнить в Blockbench любой код). **MCP Server Host** оставить `localhost`: тогда подключиться
   можно только с этого ПК. Порт 3000, адрес `/bb-mcp` по умолчанию.
4. Claude Code: в PowerShell `irm https://claude.ai/install.ps1 | iex`, потом новое окно и
   `claude --version` ([подробнее](https://code.claude.com/docs/en/setup)). Желательно поставить
   [Git для Windows](https://git-scm.com/downloads/win).
5. `git clone https://github.com/ivanafanasev006-ctrl/mc-reload-anims` и `cd mc-reload-anims`.
6. `claude mcp add blockbench --transport http http://localhost:3000/bb-mcp`
7. Открыть в Blockbench `tools/blockbench/kinetrix_rig.bbmodel`, в папке проекта запустить `claude`
   (или `claude remote-control` — тогда сессия видна и в приложении Claude на телефоне) и попросить,
   например: «прочитай tools/blockbench/README.md и сделай на открытой модели анимацию dodge_left».

Плагин при создании анимации называет её `animation.<имя>`; конвертер такую приставку отбрасывает.

## Конвертер

`kinetrix_rig.py` (Python 3, нужны `numpy` и `pillow`):

```
python3 tools/blockbench/kinetrix_rig.py make OUT.bbmodel             # собрать модель заново
python3 tools/blockbench/kinetrix_rig.py convert IN.bbmodel OUT_DIR   # анимации -> JSON playerAnimator
python3 tools/blockbench/kinetrix_rig.py preview IN.bbmodel OUT_DIR   # картинки: Blockbench и игра рядом
```

`convert` пишет для каждой анимации файл в формате emotecraft/playerAnimator (`player_animation`):
повороты, сдвиги, сгиб и ось сгиба каждой части по тикам, поворот предметов в руках. Kinetrix рисует
сгибы любой анимации playerAnimator, поэтому для проигрывания в своём моде ничего от Kinetrix не
нужно: положить JSON в `assets/<modid>/player_animation/` и проиграть через playerAnimator. Для
каждой анимации конвертер печатает, насколько поза в игре отличается от позы в Blockbench, и что
пришлось отбросить (скручивание предплечья и т.п.).
