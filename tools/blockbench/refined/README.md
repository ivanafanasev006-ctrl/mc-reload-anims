# Доработанные анимации

Здесь лежат анимации, доведённые до готовности по каркасу автора из `../animations/`: те же имена
анимаций, файл автора не меняется. Самотест проигрывает эти версии вместо черновиков. Что и почему
дорабатывается — в `CLAUDE.md` в корне репозитория.

Анимации мода движений лежат здесь в `*.bbmodel` (CI конвертирует их в
`moves/src/main/resources/assets/kinetrix_moves/player_animation`). Свои keyframe-эмоции Kinetrix
(`celebrate`) — в `kinetrix/` (CI сверяет их с `src/main/resources/assets/kinetrix/player_animation`).
