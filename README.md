# MC Reload Animations (Forge 1.20.1)

Процедурные анимации игрока в духе Mo' Bends на **playerAnimator**. Работает самостоятельно,
а с **Better Combat**, **Iron's Spells 'n Spellbooks** и **Emotecraft** плавно смешивается: без
рывков, без резких переключений и без конфликтов ног, головы и туловища.

## Что анимируется

Мод **полностью заменяет** ванильную позу своими циклами, как Mo' Bends. Все части тела, кроме головы, движутся на пружинах: с инерцией, перелётом и «тряпичной» волной, как в Fresh Animations. Сила этого эффекта задаётся параметром `general.liveliness`.

| Ситуация | Анимация |
|---|---|
| Ходьба | Перекат стопы, сгиб коленей, бёдра и плечи в противофазу, руки размашисто идут вперёд-назад |
| Спринт | Наклон вперёд, ноги работают как поршни (колено вверх, стопа вниз, бедро поднимается), руки под 90°, корпус пружинит, голова только слегка покачивается. С мечом: несёт клинок сзади лезвием наружу и машет свободной рукой |
| Торможение | Только после спринта: проскальзывает, упирается пятками, руки ловят баланс |
| Присед | Крадётся: ноги по очереди высоко поднимаются и ставятся, руки в стороны для равновесия, корпус переваливается с ноги на ногу |
| Прыжок | С разбега ведущая нога чередуется. На месте: колени подтягиваются, ноги чуть в стороны |
| Падение | Руки подняты буквой Y, ноги болтаются. При затяжном падении поза парашютиста |
| Приземление | Ноги «уходят в тело» и пружинят. Высокое с зажатой W: короткий кувырок прямо в момент касания, без W: глубокий присед. С мечом: замах и удар клинком в землю, на одном колене. После элитр: кувырок |
| Элитры | Руки отведены назад вдоль тела, ноги вместе, всё дрожит в потоке |
| Плавание | Кроль. На месте: руки и ноги разведены, ноги медленно гребут как ласты. Без спринта на ходу: гребёт руками по очереди, ноги работают сзади. Любой прыжок в воду: «дельфинчик», поза начинается ещё в воздухе |
| Лестница | Плавно перебирает: руки вверх-вниз по очереди, ноги шагают по ступеням под собой |
| Меч | Удары одной рукой всем телом с выпадом вперёд, вторая рука уходит назад для баланса, клинок поворачивается в кисти. Серия: справа, слева, сверху, **с разворота**. Белый шлейф. Хват двумя руками включается в настройках |
| Топор | Тяжёлые удары одной рукой: сверху наискось и горизонтальный, всем телом с выпадом |
| Кулаки | Боксёрская стойка, удары поочерёдно. Копает руками тоже поочерёдно, работая корпусом |
| Инструменты | Кирка стучит, лопата поддевает, мотыга рубит, топор по дереву бьёт с плеча |
| Выброс (Q) | Заметный бросок от себя с замахом, поочерёдно каждой рукой |
| Лук | Стойка вполоборота без пролезания рук и ног сквозь тело. Выстрелы чередуются: классический и с горизонтальным луком |
| Арбалет | Носит у груди двумя руками, прицеливается как из ружья, при зарядке тянет тетиву рукой |
| Щит | Полуприсед в разнесённой стойке, отдача при каждом заблокированном ударе |
| Еда и питьё | Рука подносит еду ко рту, голова трясётся при жевании |
| Урон | Удар спереди: отбрасывает назад, руки вперёд. Удар сзади: толкает вперёд, руки назад |
| Взрыв | Закрывается руками, как от светошумовой гранаты. С мечом: втыкает его и упирается |
| Тотем | Растерянно разглядывает свои руки |
| Смена рук (F) | Руки сходятся к середине и расходятся |
| Безделье | Примерно раз в 10 с без дела: разминка, приседания, чешет затылок и смотрит вдаль, палка из кармана и фехтование, руки в боки, зевает, разглядывает руки, разминает шею, нетерпеливо стучит ногой, пинает камешек. Отключается `modules.idleActions` |

| Лодка и лошадь | Гребля вёслами. На лошади качается в такт её шагу и держит поводья |
| Iron's Spells | Стойка мага по школе магии, отдача при завершении каста |

## Как устроена совместимость

Мод добавляет в стек playerAnimator каждого игрока два слоя:

1. **Базовый слой** в самом низу стека. Он добавляет наши движения поверх ванильной позы, а все
   анимации других модов играют поверх него.
2. **Гармонизатор** в самом верху стека. Каждый кадр он сравнивает итоговую позу с нашей и
   поэтому видит, какой частью тела сейчас управляет другой мод: Better Combat, Iron's,
   эмоции. Дальше он делает три вещи:
   - **кроссфейдит** каждую часть тела, когда чужая анимация начинается или заканчивается, и рывков больше нет;
   - **уступает**: наши движения рук, корпуса и головы затихают, пока ими управляет другой мод, и конфликта нет;
   - **сохраняет бег ног**: если ты атакуешь или кастуешь на ходу, ноги продолжают бежать, а не замирают в стойке.

Better Combat и Iron's не нужны ни для сборки, ни для запуска. Iron's читается через
рефлексию, а Better Combat определяется гармонизатором автоматически, как и любой другой мод на
playerAnimator.

## Установка

Нужны **Forge 1.20.1 (47.x)** и **[playerAnimator](https://modrinth.com/mod/playeranimator)** для Forge 1.20.1.
Better Combat и Iron's Spells необязательны.

Мод клиентский. На сервер его ставить не нужно, но если поставить, он ничего не сломает.
Анимации других игроков видны тебе, если мод стоит у тебя.

## Настройки

Файл `config/mcreload-client.toml`. Клавиши в «Управление → MC Reload: анимации»: включение/выключение
(по умолчанию не назначена) и меню эмоций (B).

- `general.intensity`: общая сила анимаций, от 0 до 2.
- `modules.*`: каждый модуль можно выключить отдельно.
- `modules.idleActions`: анимации безделья.
- `modules.twoHandedSwords`: держать меч двумя руками, когда вторая рука пустая (по умолчанию выкл.).
- `trails.*`: след клинка (вкл/выкл, `lifetimeSeconds`, `opacity`, `color` в формате RRGGBB).
- `compat.fadeInSeconds` / `fadeOutSeconds`: длительность перехода в чужую анимацию и обратно.
- `compat.yieldStrength`: насколько сильно наши руки и корпус уступают другим модам.
- `compat.keepLegsWhileMoving`: сохранять ли наш бег ног во время атак и кастов на ходу.
- `debug.invertKnees` / `invertElbows` / `invertTorsoBend`: если какой-то изгиб идёт не в ту сторону.

## Сборка

```
./gradlew build
```
Готовый jar лежит в `build/libs/`. Нужен JDK 17. GitHub Actions собирает мод автоматически при каждом пуше.
